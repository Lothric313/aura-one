# Aura One

Сайт: https://lothric313.github.io/aura-one/

GitHub Pages публикуется автоматически после push в `main`. Сборка для Pages:

```sh
npm ci
npm run check
npm run build -- --base=/aura-one/
```

Мобильная адаптация: [сцены, конфигурация, файлы, результаты проверок и ограничения](docs/mobile-adaptation.md). До 767 px — мобильная версия, 768–1199 px — планшет, от 1200 px сохранена десктопная композиция. Мобильная GLB Draco/WebP уже подготовлена; `npm run model:mobile` повторяет сжатие.

В сцене «Всё внутри» гарнитура слева растягивается строго вдоль своей оси, а справа остаются характеристики. При скролле к контроллерам гарнитура собирается обратно. Подключение, параметры, список файлов и замена процедурных TODO-деталей из Blender описаны в [docs/exploded-view.md](docs/exploded-view.md).

Существующий сайт сохранён: Vite, Three.js r180, GSAP ScrollTrigger, Lenis, частицы, курсор и подвал. Шапка растянута на всю ширину окна, всегда прозрачна, без CTA; активный пункт отмечается анимированной линией.

## Запуск и проверка

Крупные заголовки, цилиндрический текст и контурное слово в подвале используют Inter Black 900 из пользовательского архива Inter 4.1. Web-файл `public/fonts/Inter-Black.woff2` содержит кириллицу; лицензия сохранена рядом. Основной текст и навигация сохраняют обычную насыщенность.

В сцене поля «Aura One» — объёмный стеклянный TextGeometry из Inter Black 900. `HORIZON_Y = 0.47` находится в `src/glass-title.js`; основание учитывает кадрирование исходного видео через cover. Этот же `<video>` питает преломление. В сцене надписи только буквы и свет; видимость следует прежним переходам видео. CSS и резервное оформление — `src/world-title.css`. Подробности — `docs/immersion-scene.md`; проверка кадрирования — `node scripts/check-glass-title.mjs`.

Node.js 20.19+ / 22.12+.

Первый показ деталей и «Новой эры» использует заранее прогретые шейдеры и текстовые слои. Размер буфера продукта постоянен при раскрытии; внутренние детали сохраняются для обратной прокрутки. Мобильное кадрирование повторно использует границы геометрии. Геометрия стеклянной надписи сохранена в `public/models/glass-title.glb`: `npm run model:title` пересоздаёт её после изменения шрифта или формы. Подготовка WebGL-сцен завершается до скрытия индикатора загрузки; во время текстового цилиндра новая геометрия не строится. Проверка готовности доступна в `body.dataset.preparation`.

```sh
npm install
npm run dev
npm run check
npm run build
```

Локально: http://127.0.0.1:4188/ . Production — папка dist.

## Модель без Blender

public/models/aura-one.glb подготовлена из присланной oculus_quest_3.glb скриптами Node.js. Исходник не изменялся.

```sh
node scripts/prepare-model.mjs "путь/к/oculus_quest_3.glb"
```

Скрипт отделяет связанные компоненты геометрии, сохраняет UV корпуса и контроллеров, запекает ориентацию +Y вверх / +Z передняя панель, нормализует шлем до максимального размера 1. Три независимых корня: headsetGroup, controller_left, controller_right. Контроллеры имеют собственные центральные pivot и используют ту же единицу длины.

Отдельные компактные GLB сохраняются в artifacts/headset.glb, artifacts/controller-left.glb и artifacts/controller-right.glb. Они содержат только соответствующую геометрию и используемые текстуры. artifacts/model-preparation.json — сведения о преобразовании.

Загрузчик использует GLTFLoader + локальный DRACOLoader. Используется только присланная GLB; прежняя процедурная модель удалена. В консоли — таблицы найденных и ненайденных имён. При смене цвета за 750 мс меняется только color материалов body_mat, включая контроллеры; материал ремешка остаётся независимым. Доступны белый и серый цвета. Старый сохранённый чёрный вариант заменяется белым.

Корпус сгенерированной модели очищен от текстуры с логотипом (`node scripts/clean-shell.mjs` после повторной подготовки GLB). Камеры получили выпуклые стеклянные крышки с гладкими нормалями и отдельное отражающее окружение с узкими софтбоксами. Исходная модель и текстуры контроллеров сохранены.

## Линзы и видео

Удалены: запечённое отражение wire_085028177 из исходного GLB, прежний нарисованный овальный источник в CanvasTexture, прежний HDRI со световым пятном и светящиеся MeshBasicMaterial-кольца. Видео сохранено как изображение на оптических экранах, а не источник отражения. Файл public/media/inside.mp4 совпадает с присланным afk video.mp4 (SHA-256).

В GLB записана новая кольцевая геометрия Френеля с физическим lens_mat. Параметры: transmission .97, ior 1.5, roughness .03, clearcoat 1, envMapIntensity 1.2, dispersion .08. Корпус: envMapIntensity .6. Раскрытие использует прямой рендер без bloom и глубины резкости, чтобы сохранить бюджет для дополнительных деталей. Студийное окружение содержит два софтбокса разной яркости и контровую полосу; PMREM генерируется единожды при старте.

Ремешок получает плетёную ткань с albedo, normal и roughness. UV рассчитываются по геометрии, с одинаковой плотностью по двум осям. Старый атлас с растянутым плетением не используется на ремешке.

## Девять сцен

В блоках выбора цвета и характеристик боковые положения шлема приближены к центру, масштаб уменьшен, а переход между сторонами проходит по небольшой дуге. `src/framing.js` рассчитывает допустимый масштаб по восьми углам объёма модели, её повороту и перспективе камеры, оставляя 3.5% от края. Ограничение плавно подключается до информационных сцен и снимается перед обзором контроллеров; непрерывное движение и поздние VR-переходы сохранены.

Вся последовательность, положения, повороты и масштабы — CONFIG.motion в src/config.js. X/Y — доли полного размера кадра; Z — единицы сцены; углы — радианы; scale — ширина нормализованного шлема относительно высоты кадра. Адаптивный кадр рассчитывается через aspect камеры.

- 0–.08: передняя панель и два контроллера, без заголовков.
- В первом кадре центр шлема расположен точно по центру экрана; финальное кадрирование после выхода из VR сохранено отдельно.
- .08–.22: разворот, разлёт контроллеров, Aura One + Scroll.
- .22–.345: шлем справа, текст и выбор цвета слева.
- .345–.585: переход в «Всё внутри» — шлем плавно уходит влево и одновременно раскрывается, без ожидания в собранном положении. Модель показана ближе; характеристики проявляются справа по мере её перемещения. К .585 шлем снова собран.
- .59–.728: контроллеры справа, их описание слева.
- .695–.752: шлем отлетает влево, оба контроллера вправо; текст начинает вращение на общем звёздном фоне.
- .715–.805: собственный цилиндрический 3D Text Reveal — «НОВАЯ ЭРА ВИРТУАЛЬНОЙ РЕАЛЬНОСТИ», полный оборот 360° за один общий такт прокрутки с симметричным easing. Строки входят снизу по окружности и уходят наверх за цилиндр; прозрачность постоянная, обратная сторона скрыта. Без кода React Bits Pro.
- .780–.835: шлем возвращается спереди из правого нижнего угла, затем разворачивается линзами к зрителю.
- .805–.87: задняя часть с линзами, подход по центру переносицы между двумя оптическими осями.
- .87–.93: исходное видео поля с неподвижной красной Aura One; облачные слои удалены.
- .93–1: отлёт строго из переносицы; после .957 — разворот вперёд, затем возврат контроллеров. Контурная Aura One расположена в компактном подвале с колонками ссылок, социальными иконками и подписью Made by Lotric.

Камера сохраняет центральную ось. В сцене «Всё внутри» внутренние слои движутся только по Z. Один GSAP ticker обслуживает Lenis, canvas, камеру и текст. Общие параметры находятся в src/motion.js: 750 мс для интерфейса, навигации, смены цвета и отклика курсора; easing — симметричный smoothstep, в CSS та же кривая cubic-bezier(1/3, 0, 2/3, 1). Общий множитель MOTION.scrollSpeed = 1.44 ускоряет всю историю, включая видео с полем, в 1.44 раза относительно исходной скорости. История использует общий отсчёт прокрутки. Участок поля .87–.93 сокращён ровно вдвое: с 234.24vh до 117.12vh, с плавными границами изменения скорости. Прокрутка остальных сцен и продуктовых подписей сохранена. Общая длина — 1753.71vh на desktop и mobile; параметры поля — MOTION.field в src/motion.js. Модель, текст, фон и видео используют общий прогресс Lenis, без второго демпфирования. Интерполяция поз — монотонная кубическая Hermite/PCHIP с непрерывной скоростью на стыках. Скролл работает в обоих направлениях, без фиксаций и таймеров; scrollTo вызывается только по навигации и hash, с длительностью .75 с. Стягивание звёзд в центр выключается, пока их закрывает видео; скрытый canvas очищается, а после выхода восстанавливается исходное поле. Положение частиц задаётся прогрессом, смещение от курсора сглаживается независимо от FPS, без накопленных скоростей.

Между продуктовой сценой и исходным видео используется единый плавный переход; в середине погружения canvas продукта полностью скрыт. Надпись неподвижна, облачные слои удалены. Мобильная версия переставляет текст ниже модели. prefers-reduced-motion сокращает наклон, повороты и дыхание, сохраняя базовую фронтальную ориентацию контроллеров и порядок сцен. Текст появляется через маски строк с лёгким размытием и одновременным раскрытием слов. Display-типографика использует Inter Black 900.

Прямые переходы: #overview, #design, #specifications, #controllers, #era, #lenses, #video, #exit, #turn, #finale, #footer. #landscape и #video ведут к сгенерированному полю. Подвал сделан самостоятельно по референсу Footer 8: колонки, социальные иконки, Aura One и Made by Lotric. Слово растянуто на всю ширину экрана, чёрная заливка и тонкий полупрозрачный белый контур; видно около 80–85% высоты букв. Scroll виден с первого кадра. В текстовой сцене строки проходят полный круг без затухания.
window.aura и data-атрибуты body содержат диагностическое состояние, без аналитики.
